Proposed Pipeline Flow

1. Data Ingestion Kepler & TESS MAST archives (Time vs Flux)
2. Preprocessing NaN removal, sigma clipping, normalization
3. Feature Extraction Depth, duration, BLS period, SNR, U-shape
4. ML Classifier Random Forest / SVM / MLP candidate prediction
Problem Statement

Missions generate massive photometric data. Manual vetting is time-consuming, difficult for large catalogs, sensitive to noise, and vulnerable to eclipsing binary false positives.

Project Objectives

1. Ingest real NASA light curves.
2. Normalize & condition photometric data.
3. Extract physical transit parameters.
4. Classify candidates with confidence scoring.
