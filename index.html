Proposed System Architecture (Slide 5 Flow)

1. Data Acquisition NASA Kepler & TESS archives via MAST (Time vs Flux)
2. Preprocessing NaN removal, sigma clipping, normalization, detrending
3. Feature Extraction Depth, duration, BLS period, SNR, dip count, U-shape
4. ML Classifier Random Forest / SVM / MLP neural net candidate prediction
Problem Statement (Slide 3)

Missions like Kepler and TESS generate terabytes of stellar brightness data. Manually inspecting light curves is time-consuming, difficult for large catalogs, sensitive to noise, and hard to automate without machine learning.

Project Objectives (Slide 4)

1. Ingest real NASA light-curve data.
2. Normalize and condition photometric time series.
3. Extract physical transit parameters.
4. Classify candidates with confidence scoring.

Future Scope Implemented in this Web App (Slide 11)
  • Multi-mission compatibility: Full support for both NASA Kepler and TESS mission datasets.
  • Deep learning neural network classifier option alongside Random Forest and SVM.
  • Interactive candidate ranking algorithm based on composite SNR and U-shape score.
  • Custom CSV/FITS upload and real-time physical transit simulator.
